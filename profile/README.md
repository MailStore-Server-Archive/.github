## First Look at MailStore Server

MailStore Server is for people who administer mail and need one named archive, not a pile of PST copies. It gives you a search desk, an own store, and a short path back to mailboxes you already run. It does not replace the live servers. It sits beside them and keeps the archive close.

Work stays on mail you administer. Extra tenants wait for their own title.

---

## Mini FAQ About MailStore Server

**Is MailStore Server hard to learn?**  
No. MailStore Server is built around an archive, a search desk, and a named store.
**Can MailStore Server help on an older server?**  
Yes. MailStore Server is meant to stay steady on hardware you already administer.
**Does MailStore Server need a complex account system?**  
No. MailStore Server can start with a local profile for mailboxes you run.
**Where does MailStore Server fit best?**  
MailStore Server fits best as an archive desk next to the mail you already administer.

## Closing Notes for MailStore Server

Treat MailStore Server as a habit, not as a one-time PST dump. Open MailStore Server when you start archive work. Keep the live search small. Move finished jobs out.

If you travel between machines you administer, reopen the same named store.
